# Notes that matter for Gate A, learned from this and a later dump on the same machine:
#
# - The "Invalid object" answers are methods this model does not implement. They are part of
#   the expected shape, not failures. A registration that made them all succeed would be
#   more suspicious than one that reproduced them.
# - Several methods answer with whatever the last call left in the buffer: GetPEGorSG,
#   GetFanPWMStatus and GetFanAdjustStatus all returned 115 here, and all returned 229 in a
#   later dump where the duty was 229. They are unimplemented, and their value must never be
#   trusted or used as an anchor.
# - A later dump on this machine, taken while a custom curve was applied, read back the
#   curve OpenAorus had written - 40/57, 50/69, 60/92, 70/126, 80/172, 90/229 - followed by
#   a (0,0) terminator at slot 6 and stale values in slots 7..14. That confirms both the
#   duty conversion at 229/100 and that the terminator is written where intended.
